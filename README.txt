PORTFOLIO DELAROSE DOAMBA

CONTENU
- index.html : structure et textes du site
- styles.css : design responsive, galerie et animations
- script.js : menu, thème, compteurs, galerie, visionneuse et formulaire WhatsApp

OUVRIR LE SITE
1. Décompressez l'archive dans un dossier.
2. Ouvrez index.html dans un navigateur.
3. Pour travailler dans VS Code, ouvrez le dossier du projet. Vous pouvez lancer
   index.html avec Live Server.

Les polices, les icônes et les images du portfolio sont chargées depuis Internet.
Le formulaire de contact ouvre WhatsApp avec un message prérempli ; l'utilisateur
doit encore appuyer sur Envoyer dans WhatsApp.
